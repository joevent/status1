# Status 1 Debrief

**Erst Debrief, dann Status 1.** Anonymes 2-Minuten-Debrief für Rettungsdienst-Besatzungen – auf der Rückfahrt, vorgelesen vom Beifahrer.

- Geführter Ablauf mit Timer: Check-in → Was lief gut? → Was machen wir besser? → Was nehmen wir mit? → optional Feedback
- Antippbare Schlagworte, getrennt nach „lief gut“ und „besser machen“
- „Dringender Sprechwunsch“: Hinweise und Lehren für die nächste Besatzung auf dem Fahrzeughandy
- Auswertung für die Wachenleitung (PIN-geschützt), Export als Tabelle
- **Datenschutz:** keine Namen, keine Patientendaten, keine Uhrzeiten. Alle Daten bleiben lokal auf dem Gerät, kein Server, kein Konto.

## Installation auf dem Handy
1. Adresse der App im Browser öffnen (iPhone: Safari, Android: Chrome).
2. iPhone: Teilen-Symbol → „Zum Home-Bildschirm“. Android: Menü ⋮ → „App installieren“ bzw. „Zum Startbildschirm hinzufügen“.
3. Ab jetzt über das Symbol „Status 1“ starten. Nach dem ersten Öffnen funktioniert die App auch offline.

## Für die IT (verwaltete Geräte)
- Reine Web-App (HTML/JS), keine Installation aus einem App Store nötig.
- Verteilung per MDM möglich: iOS als Web Clip, Android über die Chrome-Richtlinie für erzwungene Web-App-Installation.
- Keine Netzwerkverbindungen außer dem Laden der App selbst und der Schriftart (Google Fonts). Keine Datenübertragung.

## Hinweise
- Hinweise zum Fahrzeug ersetzen keine offizielle Mängelmeldung.
- Die App ersetzt keine Einsatznachsorge (PSNV-E).
- Prototyp, Version 0.1.
